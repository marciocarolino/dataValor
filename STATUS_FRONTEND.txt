━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  [SERVICOS]

  AuthService (core/services/auth.service.ts)
    - login(email, password) : POST /auth/login -> salva JWT no localStorage
    - register(data)         : POST /auth/register
    - logout()               : limpa token e redireciona para /login
    - refreshToken()         : POST /auth/refresh
    - isAuthenticated()      : boolean
    - getCurrentUser()       : dados do usuario logado (decodificado do JWT)
    - verifyEmail(token)     : GET /auth/verify-email?token=...
    - resendVerification()   : POST /auth/resend-verification

  IndicatorService (core/services/indicator.service.ts)
    - getAll()                  : GET    /indicators
    - getById(id)               : GET    /indicators/:id
    - create(dto)               : POST   /indicators
    - update(id, dto)           : PATCH  /indicators/:id
    - delete(id)                : DELETE /indicators/:id
    - getMeasurements(id)       : GET    /indicators/:id/measurements
    - createMeasurement(id,dto) : POST   /indicators/:id/measurements
    - deleteMeasurement(id,mid) : DELETE /indicators/:id/measurements/:mid
    - getHistory(id)            : GET    /indicators/:id/history

  AnalysisService (core/services/analysis.service.ts)
    - getAll()   : GET  /analysis
    - create(dto): POST /analysis

  HelpService (core/services/help.service.ts)
    - Carrega conteudo de /assets/help/*.json (estatico)
    - Sem chamada ao backend

  [GUARDS]

  AuthGuard (core/guards/auth.guard.ts)
    - Protege rotas que exigem autenticacao
    - Redireciona para /login se token ausente ou expirado

  GuestGuard (core/guards/guest.guard.ts)
    - Protege rotas de visitante (login, register)
    - Redireciona para /dashboard se usuario ja autenticado

  [INTERCEPTORS]

  AuthInterceptor (core/interceptors/auth.interceptor.ts)
    - Adiciona "Authorization: Bearer <token>" em todas as requisicoes HTTP
    - Intercepta erros 401 -> chama logout() automaticamente

  [MODELOS]

  indicator.model.ts
    Interface Indicator:
      id, name, description, category, formula, unit
      goalValue, minimumGoalValue, maximumGoalValue, desiredDirection
      frequency, aggregationType
      currentValue, previousValue, variation (campos cache)
      status, chartType, color, icon
      startDate, endDate, daysRemaining
      dashboardSlot, isActive, showOnDashboard
      createdAt, updatedAt

    Interface IndicatorMeasurement:
      id, indicatorId, value, referenceDate
      periodStart, periodEnd, source, notes

    Interface IndicatorHistory:
      id, indicatorId, periodStart, periodEnd
      value, goalValue, previousValue, variationPercent
      status, notes, calculatedAt

    Enums: IndicatorStatus, IndicatorFrequency, AggregationType,
           IndicatorDesiredDirection, IndicatorCategory, IndicatorChartType

  analysis.model.ts
    Interface Analysis: id, title, content, indicatorIds, createdAt, etc.

  help.model.ts
    Interface HelpArticle, HelpSection
